# People Count Monitor

Windows에서 **왼쪽 카메라 웹 뷰어 · 오른쪽 웹 탭 · 아래 LS PLC `%MW0` · `%MW3`**를 함께 보고 프로그램 창 전체를 녹화하는 데스크톱 프로그램입니다.

## 실행

**현재 수정본은 [Windows 1.3.5 다운로드](https://github.com/seoljaegeun3-svg/people-count-monitor/actions/runs/40614312878/artifacts/12784571426)에서 ZIP을 받아 압축을 풀고 `People-Count-Monitor-1.3.5.exe`를 실행하세요(GitHub 로그인 필요). 설정 버튼의 v1.3.5 표시로 버전을 확인할 수 있습니다. Node.js나 영상 변환기를 따로 설치할 필요가 없습니다.** Source code ZIP은 실행 파일이 아닙니다.

아래 명령은 소스 코드를 개발하거나 직접 빌드할 때만 사용합니다.

Node.js 22 이상을 설치하고 이 폴더에서:

```powershell
npm ci
npm start
```

배포용 Windows EXE는 Windows PC에서 다음 명령으로 만듭니다.

```powershell
npm run dist:win
```

결과: `dist/People-Count-Monitor-1.3.5.exe`. 수신 PC에는 Node.js가 필요 없습니다. EXE는 코드 서명되지 않습니다. Windows 배포는 Windows에서 `npm ci`로 받은 Windows용 내장 변환기를 사용해야 합니다.

GitHub의 **Actions → Build Windows download → Run workflow**로도 Windows 빌드·모의 PLC 테스트·EXE 배포를 실행할 수 있습니다. 실패한 빌드는 새 다운로드를 게시하지 않습니다.

## 사용 방법

1. 카메라·PLC가 연결된 Windows PC에서 실행합니다.
2. TD2000 기본 주소 `http://192.168.1.8/`에서 시작합니다. 카메라가 HTTP Basic/Digest 인증을 요구하면 앱의 **카메라 로그인** 창에 카메라 아이디·비밀번호를 입력합니다. 웹 로그인 화면이 나오면 그 화면에서 로그인합니다. **TD2000 홈 / 로그인**은 현재 설정한 카메라의 홈 페이지로 돌아갑니다. 이전 카메라 전용 WiseAI 바로가기는 제거했습니다. 비밀번호를 주소에 넣지 마세요.
3. 오른쪽 주소창에 검색어를 입력하고 Enter 또는 **이동**을 누르면 구글에서 검색합니다. `google.com` 같은 웹 주소나 YouTube 영상 URL도 열 수 있습니다. 상단 **Google / YouTube** 버튼으로 바로 이동하고, 뒤로/앞으로/새로고침을 사용할 수 있습니다. 새 창으로 열리는 검색 결과는 같은 오른쪽 화면에 표시합니다. **연결 설정 → 브라우저 시작 주소 또는 검색어**에서 시작 화면을 바꿀 수 있습니다. iframe이 아니라 독립 Chromium 화면을 사용합니다. 일부 영상의 DRM·코덱·Google 로그인 정책은 Electron에서 제한될 수 있습니다.
4. **연결 설정**에서 PLC IP·포트·주 주소·주기를 확인합니다. **PLC 연결**을 누르면 주 주소(기본 `%MW0`)와 `%MW3`를 순차 조회합니다. `%MW3=1`은 **작업 영역 사람감지 없음**, `%MW3=0`은 **작업영역에 사람 감지**로 표시하고 감지 시 강조합니다. 다른 값은 **작업영역 상태 확인 필요**, 미수신·통신 오류·연결 중지는 **작업영역 상태 확인 불가**입니다. `%MW2`의 별도 표시와 고정 조회는 제거했습니다. **연결 중지**를 누르면 이전 값과 감지 상태를 지웁니다.
5. 가운데 세로 경계로 **좌우 비율**, 영상과 PLC 사이의 가로 경계로 **위아래 비율**을 조절합니다. 키보드로는 경계에 포커스한 뒤 해당 방향키를 사용합니다. 창의 위·아래 테두리를 끌어 높이도 줄일 수 있습니다(최소 창 크기 860×500). 비율은 자동으로 기억합니다. 카메라 상단의 `− / ＋`는 페이지 크기를 조절합니다.
6. **웹 창 추가** 또는 탭 옆 **＋**로 웹 탭을 추가하고 **×**로 닫습니다. 모든 탭을 닫으면 오른쪽 영역이 사라지고 카메라가 넓어집니다. **웹 창 추가**로 다시 열 수 있습니다. 오른쪽 영역을 닫았는지는 다음 실행에도 기억합니다. 열린 개별 탭 목록은 종료 시 초기화하며 시작 주소 설정을 사용합니다. 탭은 최대 12개입니다.

## 프로그램 녹화

1. 상단 **● 녹화 시작**을 누르고 저장 위치와 새 파일 이름을 선택합니다.
2. **녹화 중** 시간 표시를 확인합니다. 화면에 보이는 카메라·선택된 웹 탭·PLC 값·상태가 함께 녹화됩니다.
3. **■ 중지**를 누르고 **MP4 변환 중 → 저장 완료**를 기다립니다. 녹화 길이와 PC 성능에 따라 변환 시간이 걸릴 수 있습니다. **저장 폴더**로 파일을 찾을 수 있습니다.

저장 형식은 **MP4(H.264 영상 / 선택형 AAC 소리)**입니다. 전체 길이와 탐색 정보를 포함하므로 플레이어의 재생 막대를 움직여 앞뒤 원하는 시점으로 이동할 수 있습니다. 기본 저장 위치는 Windows 동영상 폴더이며 다른 폴더도 선택할 수 있습니다. 같은 이름의 기존 파일을 덮어쓰지 않으므로 새 파일 이름으로 저장하세요. 창을 최소화하면 정상적으로 캡처되지 않을 수 있으니 녹화 중에는 창을 열어두세요.

**기존 녹화 파일:** 상단 **MP4 변환**을 누르고 이전 버전으로 저장한 `.webm` 파일을 선택한 뒤 새 `.mp4` 저장 위치를 고릅니다. 변환이 완료되면 **저장 폴더**를 누르세요. 기존 WebM 원본은 유지합니다. 파일 확장자만 바꾸는 방식으로는 변환되지 않습니다.

**PC 소리 포함**은 기본적으로 꺼져 있습니다. 켜면 Windows의 PC 재생음을 함께 녹음하므로 다른 앱 소리도 포함될 수 있습니다. PC 소리를 지원하지 않는 장치에서 시작 오류가 나면 체크를 해제하고 다시 시작하세요. 마이크 녹음은 하지 않습니다. 사용 중인 프로그램 창만 영상으로 캡처하며 다른 프로그램 화면은 선택하거나 녹화하지 않습니다.

녹화 중에는 같은 폴더에 WebM 원본을 나누어 기록하고, 중지 후 내장 FFmpeg로 MP4를 완성합니다. 긴 녹화 전체를 메모리에 쌓지 않습니다. MP4 저장이 성공한 뒤 녹화 임시 원본을 정리하며, 변환 실패 시 복구용 WebM 원본을 보존합니다. 저장 공간은 변환 중 원본과 MP4가 함께 들어갈 만큼 필요합니다. 정상적인 창 닫기는 변환을 마친 뒤 종료합니다. 디스크 오류·강제 종료로 남은 불완전한 원본의 재생·변환 가능 여부는 중단 시점에 따라 다릅니다.

## 영상 인원수·PLC 비교 자동 녹화

1. 카메라에 로그인해 실제 영상을 엽니다. 창 크기·좌우/상하 비율·카메라 확대 비율을 먼저 정하세요.
2. 아래 **AI 비교 설정**을 누르고 미리보기에서 **실제 영상 영역만 드래그**합니다. 메뉴·시계·카운팅 숫자·YouTube는 영역에서 제외하세요. 기준선을 실제 출입 위치에 놓고 화살표가 입장 방향인지 확인합니다.
3. PLC 값의 의미를 선택합니다. **입장 +1 / 퇴장 −1**은 현재 인원수, **입장·퇴장 모두 +1**은 누적 통행 수입니다. **모르겠음**을 선택하면 정상 일치로 판정하지 않고 확인 영상을 보관합니다. 저장한 뒤 다시 **자동 녹화 OFF · 켜기**를 누르고 저장 폴더를 선택합니다.
4. AI가 카메라 영역에서 사람을 추적해 기준선의 입장·퇴장 통행 수를 셉니다. **PLC 변화가 없어도** 카메라 움직임·영상 통행을 기준으로 비교 구간을 엽니다. PLC만 변하는 경우도 비교합니다. 감지 전 약 5초부터 마지막 감지 후 10초까지 확인하며 연속 감지는 연장하고 최대 60초 단위로 나눕니다.
5. 영상·PLC 수가 맞고 분석 상태도 양호한 구간은 **작은 JSONL 비교 기록만** 남깁니다. **수가 다르면 Mismatch MP4**, 사람 겹침·약한 검출·추적 소실·미설명 움직임·분석 지연·통신 중단 등은 **Review MP4**로 보관합니다. 기록에는 영상 입장/퇴장 수, PLC 통행 수, 판정 이유, 영상 경로가 포함됩니다.
6. **자동 녹화 ON · 끄기**로 대기 중인 구간까지 저장을 마친 뒤 끕니다. **저장 폴더**에서 확인합니다. 저장된 MP4는 자동 삭제하지 않습니다. 정상 일치 장면의 원본은 정리하므로 영상으로 다시 확인할 수 없습니다. 수동 녹화는 자동 모드를 끈 뒤 사용합니다.

사람 감지는 내장 YOLOX-tiny 모델로 **현장 PC의 CPU에서 실행**하며 카메라 영상을 외부 서버로 전송하지 않습니다. 실제 카메라의 위쪽 시점·조명·가림·빠른 통행에 따라 놓치거나 잘못 셀 수 있습니다. 이 비교는 현장 검토를 돕는 기능이며 완벽한 누락 검출이나 정확도를 보장하지 않습니다. 초기에는 직접 센 통행과 비교해 영역·방향·신뢰도를 확인하세요. 감도는 움직임 후보, 신뢰도는 사람 인식 기준을 조절합니다. 판단을 못 하는 장면은 보관하도록 보수적으로 처리합니다.

반대 방향의 두 통행이 PLC 조회 사이에서 상쇄되면 순변화만으로는 정상 여부를 확인할 수 없어 확인 필요로 보관합니다. 값 초기화·큰 변화·PLC 수신 공백도 확인 대상입니다. PLC 쓰기는 하지 않습니다.

설정한 카메라 주소·페이지·영상 크기·확대 비율이 바뀌면 기준선을 다시 확인해야 하므로 자동 비교를 중지합니다. 오른쪽 웹 탭을 닫아 카메라 크기가 달라진 경우도 **AI 비교 설정**을 다시 저장하세요. 녹화 중에는 창을 최소화하지 말고 카메라 영상을 계속 표시하세요. 영상이 끊긴 동안의 통행은 판별할 수 없습니다.

대기 영상은 2초 단위 임시 구간으로 돌려 쓰며 정상적으로 끄면 정리합니다. 켠 직후에는 확보된 장면부터 보관하고 약 5초 뒤부터 이전 장면도 확보됩니다. 저장 공간이 부족하거나 MP4 변환이 따라가지 못하면 자동 모드를 중지하고 복구용 원본을 남깁니다. `People-Count-Recovery-...` 또는 `.people-count-auto-...` 폴더는 복구 확인 전 삭제하지 마세요. PC 소리 포함은 켜기 전에 선택합니다. 실행할 때 자동 녹화는 항상 OFF입니다.

기본 PLC 설정은 기존 [people-counter-native](https://github.com/seoljaegeun3-svg/people-counter-native) 저장소의 `plc.go`, `settings.go`에서 확인한 **LS XGT Ethernet / 192.168.1.2:2004 / %MW0 / 500ms**입니다. 실제 장비가 이 설정을 사용한다는 확인은 별도로 필요합니다. Modbus TCP용 프로그램은 아닙니다. unsigned 16-bit WORD 원시값(0~65535)을 표시합니다. PLC 내부 값의 의미와 카메라 IN/OUT 집계의 대응은 현장 로직에 따라 달라집니다.

**PLC 쓰기·리셋 명령은 구현하지 않았습니다.** 카메라 자체 IN/OUT 값은 카메라 페이지에서 확인합니다. AI 비교는 이 숫자를 긁어오는 대신 영상에서 별도로 사람을 셉니다. PLC 읽기는 앱을 시작할 때 자동 연결하지 않으며 사용자가 연결 버튼을 누릅니다.

## 설정과 로그인

Electron 사용자 데이터 폴더(`app.getPath('userData')`)의 `settings.json`에 주소·PLC 설정을, `comparison-settings.json`에 영상 영역·출입선·PLC 의미를 저장합니다. Windows 기본 경로는 `%APPDATA%\People Count Monitor\`입니다. 카메라와 오른쪽 웹 브라우저의 쿠키·로그인 세션은 별도의 로컬 브라우저 프로필에 보관합니다. 기존 YouTube 프로필과 설정은 새 버전에서도 사용합니다. 카메라 비밀번호를 앱 설정에 저장하지 않습니다. 카메라 또는 웹사이트 내 로그아웃을 사용하세요. 인증서 오류를 우회하지 않습니다.

앱 로그인 창은 사용자가 연 카메라 주소와 같은 출처의 Basic/Digest 요청에만 표시됩니다. 다른 서버나 프록시 인증에는 카메라 계정을 전달하지 않습니다. HTTP 인증 정보는 현재 Chromium 세션에 사용되며 앱이 평문 설정 파일에 저장하지 않습니다. HTTP 인증으로 로그인한 경우 프로그램을 종료하면 해당 세션이 끝납니다. 이전 카메라 IP `192.168.1.100`의 저장 주소와 새 IP `192.168.1.8`에 잘못 붙은 이전 WiseAI 경로는 TD2000 홈 `http://192.168.1.8/`로 전환합니다. 다른 IP의 사용자 지정 주소와 TD2000의 별도 사용자 지정 경로는 유지합니다. `401`은 **로그인 필요**, 다른 HTTP 오류는 **페이지 연결 실패**로 표시합니다.

npm test
npm run test:camera
# Windows EXE 빌드 후 내장 변환기와 라이선스 포함 검증
