# Publicly licensed person inference fixtures

These unmodified 512×512 PNG files are used only by local/CI tests, never as a
claim that the customer's overhead camera has been calibrated.

## `camera-cc0.png`

Photograph by **Lav Varshney**, dedicated to the public domain under **CC0**.
It is the replacement "camera" image in scikit-image 0.24.0 (the older image
from releases before 0.18 had copyright restrictions and is not used here).

- Download: https://raw.githubusercontent.com/scikit-image/scikit-image/v0.24.0/skimage/data/camera.png
- Explicit license statement in `camera()`:
  https://github.com/scikit-image/scikit-image/blob/v0.24.0/skimage/data/_fetchers.py
- CC0 legal code: https://creativecommons.org/publicdomain/zero/1.0/legalcode
- SHA-256: `b0793d2adda0fa6ae899c03989482bff9a42d3d5690fc7e3648f2795d730c23a`

## `astronaut-public-domain.png`

domain, with no known copyright restrictions according to scikit-image's
`astronaut()` documentation.

- Download: https://raw.githubusercontent.com/scikit-image/scikit-image/v0.24.0/skimage/data/astronaut.png
- NASA original: https://flic.kr/p/r9qvLn
- Explicit license statement:
  https://github.com/scikit-image/scikit-image/blob/v0.24.0/skimage/data/_fetchers.py
